# Tethera: гайд

Tethera – это холст для заметок и лора: заметки и миры разложены как карточки, связанные линиями.

## Миры

- Все ваши миры лежат в одной папке (**папка миров**). Её выбирают при первом запуске.
- Мир – это отдельное полотно: свои заметки, картинки, типы и связи.
- Стартовый экран показывает список миров. Кнопка «Открыть» открывает выбранный, «Создать» делает новый, «Переименовать» и «Удалить» работают по мирам в списке. Удалённый мир уходит в корзину и через 30 дней удаляется окончательно.
- Из мира вернуться на стартовый экран можно через «☰ Проект» → «Главное меню» или клавишей **Ctrl+M**.
- При первом запуске создаётся мир «Пример». Его можно удалить.

## Сохранение

- **Ctrl+S** сохраняет открытый мир в его папку.
- Файл `.tether` создаётся только через «Экспорт». Экспорт не меняет мир.
- **Ctrl+Q** сохраняет мир и закрывает приложение. Закрытие окна тоже сохраняет мир.

## Заметки

- Заметка – это карточка на холсте. Двойной щелчок открывает её в боковой панели.
- Текст заметки пишется в формате Markdown с BBCode-тегами (`[b]`, `[i]`, `[color=...]` и другие).
- Связь создаётся записью `[[Название]]` в тексте. Связь видна сразу, как только заметка с таким названием существует.
- `[[Название|Подпись]]` показывает подпись вместо названия.
- Связь вручную (Ctrl+клик между карточками) не зависит от текста.
- Пробел + клик по карточке закрепляет её на экране: она движется вместе с холстом, пока её не открепишь таким же кликом с Пробелом.

## Типы

- В каждом мире есть типы: Персонаж, Событие, Место, Фракция, Предмет. Их можно переименовывать, удалять и создавать свои.
- Тип задаёт цвет карточки и набор полей: текст, число, дата или список.
- Цвет карточки можно поменять вручную, но тогда он перекроет цвет типа.
- Панель фильтра по типам затеняет карточки, которые не попадают в выбранные типы. Связи при этом остаются видны.
- Удаление типа не удаляет заметки: они становятся «без типа».

## Картинки

- Картинки добавляются кнопкой «Вставить картинку» или командой «Картинки» в меню.
- В тексте картинка пишется так: `![описание|300](путь)`, где `300` – ширина в пикселях.
- «Удалить неиспользуемые картинки» переносит в корзину картинки, на которые не ссылается ни одна заметка.
- Картинка больше 8000 × 8000 пикселей не открывается.

## Экспорт и импорт

- «Экспорт» открывает окно с галочками: отмеченные заметки попадут в файл `.tether`. «Экспортировать весь мир» отмечает все заметки.
- «Включить связанные» добавляет заметки, на которые ссылаются отмеченные. Их можно снять вручную.
- Открыть `.tether` можно двумя способами: импортировать в текущий мир или создать новый. При совпадении id заметка импортируется копией с новым id.
- Файлы больше 2 ГБ, с повреждённой структурой или с подозрительным сжатием не открываются. Мир при этом не меняется.

## Корзина и резервные копии

- Удалённые заметки можно вернуть: «Корзина» → «Восстановить из корзины».
- «Очистить корзину сейчас» удаляет всё из корзины окончательно и спрашивает подтверждение. Резервные копии это не затрагивает.
- Каждый день при первом запуске создаётся резервная копия мира. Хранятся последние 7.

## Настройки

- Окно настроек открывается из «☰ Проект» и клавишей **Ctrl+,**.
- Изменения применяются только по кнопке «Сохранить». «Отмена» ничего не меняет.
- В базовых настройках: язык интерфейса (Авто, English, Русский), сетка, толщина линий, цвет по умолчанию, уменьшенное движение.
- В расширенных: сколько резервных копий хранить, включать ли связанные заметки при экспорте по умолчанию.
- Смена языка применяется после перезапуска.
